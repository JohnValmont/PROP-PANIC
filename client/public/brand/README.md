# PROP PANIC logo kit

Generated by `tools/brand-logo.cjs`. All text is outlined, so the SVGs render the same everywhere without Fredoka installed.

| File | Use |
| --- | --- |
| `logo.svg` / `logo.png` | Primary stacked logo (transparent). Use on dark or busy backgrounds. |
| `logo-horizontal.svg` / `.png` | Icon + one-line wordmark, for headers and banners. |
| `logo-mono-white.svg`, `logo-mono-ink.svg` | One-colour versions for overlays, stamps, merch. |
| `icon.svg`, `icon-512.png`, `icon-192.png` | App / store / PWA icon. |
| `favicon.svg`, `favicon-32.png` | Simplified mark that stays legible at 16-32 px. |
| `social-card.svg` / `.png` | 1200x630 Open Graph / link preview image. |

Colours (same tokens as `client/src/style.css`): yellow `#ffd166`, pink `#ef476f`, ink `#22223b`, navy `#1b2a4a`, sweat-drop cyan `#5fe0ff`.

Rules: keep clear space of at least the googly eye's width around the logo; don't recolour PROP/PANIC independently,
stretch it, or remove the ink outline on the colour version.
